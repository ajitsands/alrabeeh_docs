Navigation Length

Maximum 11 pages to cycle through before specialized module views open. After Dashboard, all other modules are accessed via sub-navigation or quick-filter panels within each module.

Mandatory Precedence

CORE-02 supersedes all navigation rules. Users cannot bypass steps or skip modules. The blueprint explicitly validates each flow point before deliverable acceptance.

Parallel Workflow

While all three roles navigate the same sequence, each stage supports unique context: Reception books → Doctor marks progress → Admin approves → Billing closes → Feedback triggers

Session Management

24-hour audit lock on Hold-marked records (DASH-12). Admin oversight overrides allowed only with justification. Daily sign-off handles dual logins at shift change.

Quick Surface Hooks

Horizontal quick-filter tabs at top of each module: All Patients / Calendar Today / Patients Need Contact / Dentist's Favorite TP keep specialist views one-click away.

Offline Capability

Navigation sequence supports fully offline operation. SQLite caches all module views; RabbitMQ syncs updates when connection restored. No lost context across internet drops.
