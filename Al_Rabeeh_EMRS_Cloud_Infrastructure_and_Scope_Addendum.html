3.3 Critical Infrastructure Prerequisites for Connecting Your 6 Branches

If the central server is hosted in-house at your Head Office or Main Clinic, the remaining 5 branches must be able to securely query and update patient files in real time. The following physical and networking components are mandatory to ensure continuous uptime and NHRA data protection:

Central Server (HQ) Hamad Town Branch Muharraq Branch Isa Town Branch Budaiya Branch Galali Branch Sitra Branch

1. HQ Dedicated Business Fiber + Static IP

A high-reliability Business Fiber connection (minimum 50–100 Mbps symmetrical) with a permanent Public Static IPv4 Address from Batelco, Zain, or stc Bahrain is required at the central server location (~BD 80 – BD 150 / month). Residential or dynamic broadband lines cannot be used.

2. Central Next-Gen Enterprise Firewall

A hardware Next-Generation Firewall (e.g. Fortinet FortiGate 60F/70F or Sophos XGS 116) deployed at HQ (~BD 450 – BD 650) to manage intrusion prevention (IPS), DoS attack mitigation, SSL inspection, and IPsec VPN tunnel termination from the branches.

3. Secure Site-to-Site IPsec VPN Tunnels

Recommended Architecture: Deploying managed VPN routers (e.g. FortiGate 40F or MikroTik hEX) at each of the 6 branches creating encrypted Site-to-Site IPsec VPN tunnels. Reception workstations access the server over a private internal subnet (e.g. https://192.168.10.50), completely hidden from the public internet.

4. 24/7 Climate Control & Physical Security

The physical server must be housed in an enclosed, lockable server rack cabinet within an air-conditioned room running continuously at 18°C–22°C (24/7/365). Power cuts or A/C failures in Bahrain summers can cause catastrophic thermal throttling or hardware shutdowns.

5. Smart CPR Hardware LAN/WAN Integration

The custom SaNDS Lab .NET CPR Card Windows Service installed on each reception workstation communicates with the central server API over the VPN/LAN. Stable network latency (<25ms) is required between all branches and HQ for instantaneous patient retrieval.

6. Ongoing SysAdmin & Disaster Recovery

Client must designate an internal IT administrator (or retain a managed IT support vendor) responsible for monitoring daily NAS backups, applying Ubuntu OS security patches, testing UPS battery degradation, and swapping failed SSD drives.

Scope Demarcation & Responses to Client Clarifications

Complete Alignment with Client Expectations

We appreciate Al Rabeeh Dental Center's clear articulation regarding standard clinic management functionality. Below is our definitive, legally binding scope demarcation:

100% INCLUDED in the Existing Proposal (BD 8,400.000)
Covered Scope
  • Master Creation & Management: Complete administrative masters for Clinics, Branches (all 6 branches), Treatment Rooms, Dental Chairs, Services, Procedures, ICD-10 Diagnostic Codes, ADA/FDI Dental Codes, and Price Lists.
  • User & Doctor Management: Comprehensive profiles for Receptionists, Nurses, General Dentists, Orthodontists, Specialists, Branch Managers, Cashiers, and Admins.
  • Role-Based Access Control (RBAC): Granular permissions matrix ensuring doctors view clinical workflows, receptionists manage queues and bookings, and admins control approvals.
  • Standard Validations & Clinical Logic: Overlapping appointment locks, doctor duty schedule enforcement, Bahrain CPR 9-digit format check, 8-digit mobile phone validation, and mandatory field guards.
  • Confidentiality, Security & Audit Trail: AES-256 database encryption at rest, HTTPS SSL in transit, immutable audit logs tracking user, timestamp, IP, and before/after values for all records.
  • All 11 Blueprint Modules: Dashboard & 6 KPIs, Multi-Doctor Calendar, MSD Leakage Tracker, Fail Visit Rollover, Ortho Continuity, TP Value Recall, Feedback Calls, Lab Tracker with Shade Master, Insurance Claims, Patient Journey Compliance, Billing Cashier Register.
  • Continuous Stage-by-Stage Guidance: SaNDS Lab technical delivery leads will actively walk through each milestone demo and UAT session, guiding Al Rabeeh on configuration, master data population, and workflow optimization.
Items Requiring Separate Discussion & Quotation
Out of Scope
  • Pharmacy ERP & Full Inventory Purchasing: Full enterprise pharmaceutical stock replenishment, supplier purchase orders, and expiry batch dispensing (basic clinic procedure consumable linking is included, but full pharmacy purchasing ERP is separate).
  • Automated Laboratory Machine Hardware Interfacing: Bidirectional HL7/ASTM robotic interfaces to external automated blood or diagnostic analyzers (the EMRS includes manual lab slip entry and 3-lane chat).
  • In-House Radiology / PACS DICOM Archive: The EMRS links to digital X-ray image files and external URLs; a dedicated hospital-grade PACS DICOM archive server is not included.
  • Third-Party Messaging Gateway Fees: Official WhatsApp Business API per-template utility charges or bulk SMS SMS-gateway credits (billed directly by Meta / Batelco / Zain at actual consumption).
  • Third-Party TPA API Licensing Fees: Any proprietary API connector charges levied directly by insurance portals (Globemed, Mednet, Gulf Union) for automated EDI transmission.
  • Revisions Exceeding the 3-Revision Cap: Iterations on the same feature exceeding three rounds will be handled via standard 10% Milestone Change Requests (CR) as agreed in governance rules.
Clarification on Post-Deployment Support & Warranty

Regarding the client's reference to "one year of support":

  • Included in BD 8,400 Contract: Milestone MS-BUF provides 1 Full Month (4 Working Weeks) of Multi-Branch Pilot & Hypercare Support, followed by our standard 60-Day Post-Go-Live Comprehensive Warranty covering bug fixes, defect rectification, and performance tuning at zero additional cost.
  • Extended 1-Year Comprehensive SLA: Following the warranty period, ongoing annual Level-2 and Level-3 application support (Annual Maintenance Contract / AMC) can be seamlessly bundled with the Vendor-Managed Cloud Hosting or engaged as an annual SLA agreement at standard industry rates (15% of software value / year).
